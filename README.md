# PlayMotion — The Gaming Platform

PlayMotion is a shelf of quick browser-based games: tycoons, racers, builders, action, and strategy games. Pick any game, click **Play**, and play directly in your browser.

## Features

- **Instant New-Tab Launch**: Click **Play** (or tap a game thumbnail) on any card to open the game directly in a new browser tab with no downloads or installs required.
- **Category Filtering**: Filter games across Tycoon, Racing, Builder, Action, and Strategy shelves with a responsive layout.
- **Wide Variety of Games**:
  - **Little Vale** — Isometric city builder
  - **Canyon GP** — 3D canyon racing
  - **DuneDrift** — High-speed drift & police pursuit
  - **Tiny Acres** & **Kheti Farm** — Farming & harvest simulators
  - **Mini Motel**, **Harbour Tycoon**, & **Taxi Tycoon** — Management and tycoon simulators
  - **Tower War** & **Boss Block** — Strategic tower and puzzle defense
  - **Stickman Dash**, **MobMaster**, **Thread Peak**, **Echoes of the Iron Palace**, & **Last Isle: Zombie World** — Action, brawler, and survival adventures

## Quick Start

Open `index.html` in any modern web browser or serve locally:

```bash
# Python
python -m http.server 8000

# Node.js (npx)
npx serve .
```

Then visit `http://localhost:8000`.
